# ⚡ El Rincón Mágico de un Desarrollador Potterhead

Este repositorio contiene el proyecto personal de portafolio y práctica de desarrollo web centrado en el universo de **Harry Potter**. Es un homenaje a la saga, explorando cómo sus temas de amistad, valentía y conocimiento inspiran mi camino en el desarrollo.

El proyecto está diseñado bajo pautas de **semántica HTML5** y **maquetación moderna con Flexbox** para consolidar habilidades básicas de estructura y estilo.

---

## 🧙 Características Principales

* **Estructura Semántica:** Uso riguroso de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, y `<footer>`.
* **Diseño Temático:** Paleta de colores y fuentes inspiradas en la estética mágica de Hogwarts.
* **Componentes Avanzados (CSS puro):**
    * **Menú Desplegable (Dropdown):** Navegación anidada funcional con `:hover` y `position: absolute`.
    * **Maquetación Dinámica:** Uso de Flexbox para tarjetas adaptables en las secciones de Casas y Personajes.
